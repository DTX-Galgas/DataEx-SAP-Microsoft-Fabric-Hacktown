# DataEx-SAP-Microsoft-Fabric-Hacktown

Olá, pessoal.

Para que os participantes consigam executar os labs do Hackday em seus próprios tenants, será necessário garantir previamente os seguintes acessos e configurações:

Acesso a um workspace do Microsoft Fabric associado a uma capacidade ativa, preferencialmente F16 ou superior;
Permissão de, no mínimo, Contributor no workspace que será utilizado durante os labs;
Configuração administrativa do Microsoft Fabric habilitada para os participantes:
Users can create Fabric items;
Liberação para criação dos itens necessários durante os labs, como:
Pipelines;
Notebooks;
Lakehouses;
Conexões;
Dataflows e demais itens do Microsoft Fabric;
Acesso de rede para que o Microsoft Fabric consiga consumir a API REST disponibilizada pelo SAP HANA.

A API do SAP HANA estará publicada na internet e não terá restrição por endereço IP. Dessa forma, o Pipeline do Microsoft Fabric poderá acessá-la diretamente, sem a necessidade de instalação ou configuração de gateway.

Recomendamos que todos os acessos, permissões e configurações sejam validados antes da realização do Hackday, garantindo que os participantes consigam executar os labs sem bloqueios relacionados ao ambiente ou às permissões do tenant.
